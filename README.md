# CSS Portfolio
This project is based off of the [Getting Started with CSS, v2](https://master.dev/courses/getting-started-css-v2/)
course hosted on master.dev. This course-long project involved creating a mock
portfolio page using just HTML and CSS, including a CSS only color scheme 
switcher. This project had some basic page structuring with HTML, but mainly
focused on using basic CSS, Flexbox, and Grid to layout and style the page.

> Disclaimer: None of the information or media on the website applies to me. All
content is sample content which were retrieved from the course. This portfolio
does not act as an accurate portfolio of me or my work.

The webpage is hosted using GitHub Pages [here](https://austindloar.github.io/fem-css-portfolio).
